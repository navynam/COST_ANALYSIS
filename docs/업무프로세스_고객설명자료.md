> **대상**: 고객 업무 담당자  

---

## 1. 시스템 개요

본 시스템은 협력사로부터 수신한 **견적서(Excel)**를 자동으로 파싱하고, 원가 구조를 분석하며, 이상치를 감지하여 견적의 정확성과 적정성을 검증하는 시스템입니다.

### 핵심 가치

| 가치 | 설명 |
|------|------|
| **자동화** | Excel 견적서를 AI가 자동 파싱하여 수작업 최소화 |
| **정확성** | 원본 대조 검증으로 파싱 오류 즉시 보정 |
| **원본 보존** | 원본 데이터를 직접 수정하지 않고 노트/하이라이트로 피드백 |
| **투명성** | 모든 계산의 근거와 수식을 투명하게 공개 |
| **비교 분석** | 이전/타 견적서와 비교하여 원가 적정성 판단 |

### STEP 6. 원본 데이터 피드백 (노트 + 하이라이트)

#### 🔴 왜 원본 데이터를 직접 수정하면 안 되는가?

> **원본 견적서는 협력사가 작성한 공식 제출 문서입니다.**
>
> 원본 데이터를 직접 수정하면 다음과 같은 문제가 발생합니다:
>
> | 문제 | 설명 |
> |------|------|
> | **법적 문제** | 견적서는 계약의 기초 자료입니다. 원본을 임의로 수정하면 원본의 진정성이 훼손되어 분쟁 시 증거로 인정되지 않을 수 있습니다. |
> | **감사 추적 불가** | 원본이 변경되면 "누가, 언제, 무엇을" 변경했는지 추적이 불가능해집니다. |
> | **책임 소재 불명확** | 원본 수정 시 오류의 책임이 원 작성자(협력사)에 있는지, 수정자(분석 담당자)에 있는지 불분명해집니다. |
> | **데이터 정합성** | 원본 파일의 수식/참조가 연결되어 있어 일부만 수정하면 전체 데이터 정합성이 깨질 수 있습니다. |
> | **재현 불가** | 원본이 변경되면 동일한 분석을 재현할 수 없습니다. |
>
> **따라서 본 시스템은 원본을 보존하고, 피드백만 전달하는 방식을 채택합니다.**

#### 피드백 방식

```
원본 Excel 파일
  │
  ├── 📝 노트 추가 (셀에 코멘트)
  │   "이 단가는 시장가 대비 33% 높습니다.
  │    재확인 바랍니다."
  │
  ├── 🟨 셀 하이라이트 (배경색 표시)
  │   오류/주의가 필요한 셀에 노란색 강조
  │
  └── 💾 피드백이 포함된 Excel 저장
      → 협력사에 반환하여 수정 요청
```

#### 프로세스

```
사용자 (분석 담당자)              시스템                    협력사
  │                              │                         │
  │── 오류 항목에 노트 작성 ──────▶│                         │
  │── 주의 셀에 하이라이트 ───────▶│                         │
  │── [피드백 저장] 클릭 ─────────▶│                         │
  │                              │── 원본 + 노트/하이라이트  │
  │                              │   포함된 Excel 생성       │
  │                              │── 피드백 파일 전달 ──────▶│
  │                              │                         │── 원본 수정
  │                              │                         │── 수정본 재제출
  │◀── 수정된 견적서 재업로드 ───────────────────────────── │
```

#### 화면 — 원본 피드백

```
┌─────────────────────────────────────────────────────┐
```

#### 원본 보존 vs 피드백 비교

| 구분 | 원본 직접 수정 (❌ 금지) | 노트/하이라이트 피드백 (✅ 채택) |

| 책임 소재 | 불명확 | **작성자(협력사)가 직접 수정** |
| 데이터 정합성 | 수식 깨짐 위험 | **원본 수식 유지** |
| 재현성 | 재현 불가 | **동일 분석 재현 가능** |
| 법적 효력 | 진정성 훼손 | **원본 진정성 유지** |

### STEP 7. 견적서 비교 분석

#### 프로세스

```
사용자                          시스템
  │                              │
  │── Step 1: 아이템 선택 ────────▶│
  │   (코드/품명 검색)              │── 해당 아이템 견적서 목록 조회
  │                              │
  │── Step 2: 비교 대상 선택 ─────▶│
  │   (2~4개 견적서 선택)           │── 선택된 견적서 데이터 로드
  │                              │
  │◀── Step 3: 비교 결과 ─────── │
  │   항목별 나란히 비교            │── 최저가/최고가 강조
  │   계산식 비교 가능              │── 항목별 차이 계산
```

#### 화면 — 비교 결과

```
┌──────────┬──────────┬──────────┬──────────┐
│ 항목      │ 업체 A   │ 업체 B   │ 업체 C   │
│ 재료비    │ 1,076 ▼  │ 1,234    │ 1,180    │
│ 가공비    │ 1,157    │ 1,089 ▼  │ 1,201    │
│ 제경비    │   611    │   580 ▼  │   645    │
│ ──────── │ ──────── │ ──────── │ ──────── │
│ 총원가    │ 2,844    │ 2,903    │ 3,026    │
└──────────┴──────────┴──────────┴──────────┘
  ▼ = 최저가 강조 (녹색)
```

#### 비교 대상

|-----------|------|

| **타 협력사** | 동일 부품에 대한 다른 협력사 견적서와 가격 비교 |
| **시장 데이터** | 원자재 시장가 대비 원가 적정성 비교 |

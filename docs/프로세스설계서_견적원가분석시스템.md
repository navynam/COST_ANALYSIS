## 1. 전체 업무 프로세스 흐름

### 1.1 메인 워크플로우

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  1단계    │    │  2단계    │    │  3단계    │    │  4단계    │    │  5단계    │
│ 파일 업로드│ →  │ 데이터    │ →  │ 데이터    │ →  │ 원가     │ →  │ 결과     │
│ + 자동추출│    │ 검증      │    │ 분석      │    │ 비교     │    │ 저장/ERP │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
  /parsing        /verification    /analysis       /comparison     골든셋
  /parsing_card                                                   Excel 다운로드
```

### 1.2 상태 전이도

```
                    ┌─────────┐
         업로드 →   │ 추출중   │
                    └────┬────┘
                         │ AI 자동 추출
                    ┌────▼────┐     ┌─────────┐
                    │ 검증중   │ ──→ │  실패    │  (추출 오류 시)
                    └────┬────┘     └────┬────┘
                         │ 검증 완료         │ 재처리
                    ┌────▼────┐         ┌──▼──┐
                    │검증완료  │         │재업로드│
                    └────┬────┘         └─────┘
                         │ 분석 시작
                    ┌────▼────┐
                    │ 분석중   │
                    └────┬────┘
                         │ 분석 완료
                    ┌────▼────┐
                    │분석완료  │ → 골든셋 확정 → ERP 등록
                    └─────────┘
```

### 2.1 [1단계] 파일 업로드 및 데이터 추출

#### 2.1.1 프로세스 흐름

```
사용자                        시스템                          AI 엔진
  │                            │                              │
  │── Excel 파일 업로드 ──────▶│                              │
  │   (드래그앤드롭/클릭)       │                              │
  │                            │── 파일 검증 ──────────────▶  │
  │                            │   (확장자, 크기, 형식)        │
  │                            │                              │
  │                            │◀── 파일 구조 분석 결과 ─────│
  │                            │                              │
  │                            │── 데이터 추출 요청 ────────▶│
  │◀── 진행률 실시간 표시 ─────│                              │
  │   (0% → 100%)              │                              │
  │                            │◀── 추출 완료/실패 ──────── │
  │◀── 상태 업데이트 ──────────│                              │
  │   (추출중 → 검증중/실패)    │                              │
```

#### 2.1.2 입력/출력
| 구분 | 내용 |
|------|------|
| **입력** | Excel 파일 (.xlsx, .xls) |
| **처리** | AI가 견적서 구조 자동 인식 → 재료비/가공비/제경비 항목 분류 |
| **출력** | 파싱된 항목 목록, 신뢰도 점수, 이상치 감지 결과 |
| **실패 시** | 오류 사유 표시, 재업로드 안내 |

#### 2.1.3 비즈니스 규칙
| 규칙 | 설명 |
|------|------|
| BR-001 | 지원 파일 형식: .xlsx, .xls |
| BR-002 | 동시 다중 파일 업로드 가능 |
| BR-003 | 추출 실패 시 "실패" 상태로 전환, 재처리 가능 |
| BR-004 | 추출 완료 시 자동으로 "검증중" 상태 전환 |

### 2.3 [3단계] 원가 분석

#### 2.3.1 프로세스 흐름

```
사용자                        시스템                     AI 엔진
  │                            │                          │
  │── 분석 페이지 진입 ────────▶│                          │
  │                            │── 검증 데이터 로드        │
  │                            │── 원가 구조 분석 ────────▶│
  │                            │◀── 분석 결과 ────────── │
  │                            │                          │
  │◀── 3가지 뷰 표시 ──────── │                          │
  │   표준뷰 / 리스트뷰 / 관계도                          │
  │                            │                          │
  │── 이상치 항목 클릭 ────────▶│                          │
  │◀── AI 판단근거 표시 ────── │                          │
  │                            │                          │
  │── 골든셋 탭 클릭 ──────────▶│                          │
  │◀── 원가계산서 양식 표시 ── │                          │
  │                            │                          │
  │── Excel 다운로드 ──────────▶│                          │
  │◀── .xls 파일 다운로드 ──── │                          │
```

#### 2.3.2 분석 뷰 상세

| 뷰 | 목적 | 주요 기능 |
|----|------|-----------|
| **표준뷰** | 카테고리별 원가 구조 파악 | 재료비/가공비/제경비 계층 구조, 신뢰도 바, 이상치 팝오버 |
| **리스트뷰** | 항목별 상세 비교 | 평면 테이블, 정렬/검색, 인라인 편집 |
| **관계도** | 항목 간 의존성 파악 | 노드 그래프, 클릭 시 우측 상세 패널, AI 판단근거 |
| **골든셋** | 최종 원가계산서 | 공식 양식, Excel 다운로드, 인쇄 |

#### 2.3.3 이상치 감지 프로세스

```
AI 엔진 분석
    │
    ├── 시장가 대비 비교 → 33% 초과 시 이상치 판정
    ├── 과거 분기 평균 대비 → 편차 기준 초과 시 경고
    └── 전체 비율 기준 → 비정상 비율 시 주의
         │
         ▼
  ┌──────────────┐
  │ 이상치 표시    │ → ⚠️ 배지 + AI 판단근거
  │ (팝오버)       │ → "과거 3분기 평균 ₩14,200 대비 +33.2% 높음"
  └──────────────┘
```

## 3. 모델관리 워크플로우

### 3.1 수식 관리 프로세스

```
┌─────────────────────────────────────────────────────────┐
│                    관리자 (김관리)                        │
│  ┌─────────┐  ┌─────────┐  ┌──────────┐                │
│  │수식 추가 │  │수식 편집 │  │수식 삭제  │  → 즉시 반영   │
│  └─────────┘  └─────────┘  └──────────┘                │
│  + 적용 부서 체크박스 (전체/견적1팀/견적2팀/...)         │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│                일반 사용자 (이분석, 박검증)               │
│  ┌──────────────┐    ┌──────────────┐                   │
│  │ 수정 요청 제출 │    │ 추가 요청 제출 │                   │
│  │ + 변경 사유    │    │ + 요청 사유    │                   │
│  └──────┬───────┘    └──────┬───────┘                   │
│         │                    │                           │
│         ▼                    ▼                           │
│  ┌──────────────────────────────────┐                   │
│  │        변경 요청 탭 (대기)        │                   │
│  └──────────────┬───────────────────┘                   │
│                 │                                        │
│         ┌───────▼───────┐                                │
│         │   관리자 검토   │                                │
│         ├───────┬───────┤                                │
│         │       │       │                                │
│     ┌───▼──┐ ┌─▼────┐                                   │
│     │ 승인  │ │ 반려  │                                   │
│     │+부서  │ │+코멘트│                                   │
│     └───┬──┘ └──────┘                                   │
│         │                                                │
│         ▼                                                │
│  수식에 자동 반영 (선택된 부서에만)                       │
└─────────────────────────────────────────────────────────┘
```

### 3.2 변경 요청 상태 관리

| 상태 | 설명 | 사용자 액션 | 관리자 액션 |
|------|------|-------------|-------------|
| **대기** | 요청 접수 | 취소 가능 | 승인/반려 |
| **승인** | 관리자 승인 완료 | 조회만 | 적용 부서 표시 |
| **반려** | 관리자 반려 | 코멘트 확인 | 반려 사유 기록 |

### 3.3 부서별 모델 적용

```
수식: 재료비 = Σ(단가 × 수량 × (1 + 로스율))
  │
  ├── 적용: [전체] → 모든 부서에서 이 수식 사용
  │
  └── 변경 요청 승인 후:
      ├── 견적1팀: 재료비 = Σ(단가 × 수량 × (1 + 로스율) × 환율보정계수)
      └── 나머지: 원본 수식 유지
```

### 3.4 비즈니스 규칙
| 규칙 | 설명 |
|------|------|
| BR-016 | 핵심(core) 수식은 삭제 불가 |
| BR-017 | 이미 대기 중인 요청이 있으면 동일 수식 중복 요청 불가 |
| BR-018 | 승인 시 적용 부서를 체크박스로 선택 (전체 또는 개별) |
| BR-019 | 승인된 변경은 즉시 모델 관리 탭에 반영 |

| 검증 진행 중 | 정보 | "자동 검증 프로세스 진행 중" |
| 인사이트 리포트 | 정보 | "원가 절감 포인트 3건 발견" |

### 6.2 알림 → 액션 연결

```

[처리 지연]   ──클릭──▶ /parsing_card (재처리)
[ERP 등록]    ──클릭──▶ /parsing_card (등록 프로세스)
```

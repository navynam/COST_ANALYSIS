# 견적 원가 분석 시스템 - 화면 설계서

> **프로젝트**: 현대모비스 견적 원가 분석 시스템  
> **버전**: v2.0  
> **작성일**: 2026-04-07  
> **배포 URL**: https://navynam.github.io/COST_ANALYSIS  

---

## 1. 시스템 개요

### 1.1 목적
견적서(Excel)를 업로드하면 AI가 자동으로 데이터를 추출하고, 검증/분석/비교를 통해 원가 적정성을 판단하며, 최종적으로 ERP 시스템에 등록할 데이터를 생성하는 시스템입니다.

### 1.2 기술 스택
| 구분 | 기술 |
|------|------|
| Frontend | React 18 + TypeScript |
| UI Framework | MUI (Material-UI) v5 |
| 차트 | Recharts |
| 라우팅 | React Router v6 (HashRouter) |
| 상태 관리 | React Hooks + Context API |
| Excel 처리 | SheetJS (xlsx) |
| 배포 | GitHub Pages |

### 1.3 메뉴 구조
```
┌─ 모비스 로고 + "견적서 분석" ──────────────────────┐
├─ 대시보드                    /dashboard             │
├─ [분석 플로우] ──────────────────────────────────── │
│   ├─ 견적서 분석             /parsing                │
│   ├─ 견적서 분석(Card)       /parsing_card           │
│   ├─ 견적서 비교             /comparison             │
│   └─ 인사이트 스튜디오       /insight                │
├─ [관리] ─────────────────────────────────────────── │
│   ├─ 모델관리                /models                 │
│   ├─ 이력/알림               /history                │
│   └─ 설정                    /settings               │
└──────────────────────────────────────────────────── ┘
```

│  │             │ │ │              │  │ │              │      │
│  │[노트] 처리중│ │ │[노트] [검증] │  │ │[노트] [분석] │      │
│  └─────────────┘ │ └─────────────┘  │ └─────────────┘      │
└──────────────────┴──────────────────┴──────────────────────┘

#### 카드 상태별 표시
| 상태 | 동적 콘텐츠 | 버튼 |
|------|-------------|------|
| 추출중 | 프로그래스바 + 진행률 % | 처리중 (비활성) |
| 검증중/완료 | 파싱 항목수, 신뢰도, 이상치 | 검증하기 / 분석하기 |
| 분석중 | 파싱 결과 요약 | 분석 상세보기 |
| 분석완료 | 파싱 결과 요약 | 분석 결과 보기 |
| 실패 | 오류 사유 메시지 | 오류 확인 |

#### 역할별 기능

|------|-----------|-----------|

| 일반 사용자 | 수정 요청 제출, 추가 요청 제출 | 본인 요청 조회/취소 |

#### 변경 요청 탭
```
  [전체 3] [대기 1] [승인 1] [반려 1]    ← 클릭 필터링

  │  [+ 환율보정계수]                                     │
  │  요청 사유: 수입 원자재 환율 보정 필요                 │
  │  [검토 및 승인] [반려]                                │

```

## 3. Feature 모듈 패턴

### 3.1 표준 디렉토리 구조

```
features/{feature-name}/
├── {Feature}Page.tsx            ← 페이지 컴포넌트
├── {Feature}Page.module.css     ← CSS Module (레이아웃 전용)
├── components/                  ← 하위 컴포넌트
│   ├── ComponentA.tsx
│   └── ComponentB.tsx
├── data/                        ← 목업 데이터 (향후 삭제 예정)
│   └── mockData.ts
├── hooks/                       ← 커스텀 훅 (UI 상태 관리)
│   └── use{Feature}.ts
├── services/                    ← 서비스 레이어 (API 호출 + 비즈니스 로직)
│   └── {feature}Service.ts
└── types.ts                     ← 타입 정의
```

### 3.2 레이어 책임 분리

| 레이어 | 파일 | 책임 | 예시 |
|--------|------|------|------|
| **Page** | `XxxPage.tsx` | 화면 구성, 레이아웃 | JSX 렌더링, 이벤트 핸들링 |
| **Component** | `components/*.tsx` | 재사용 UI 컴포넌트 | ListView, FileCard, StatusBadge |
| **Hook** | `hooks/useXxx.ts` | UI 상태 관리 (useState, useEffect) | 모달 열기/닫기, 탭 전환, 폼 상태 |
| **Service** | `services/xxxService.ts` | API 호출, 데이터 변환, localStorage | fetchQuotations(), loadFormulas() |
| **Type** | `types.ts` | 인터페이스/타입 정의 | FileItem, CostRow, Formula |
| **Data** | `data/mockData.ts` | 목업 데이터 (개발용) | initialFiles, costGroups |
| **CSS** | `*.module.css` | 레이아웃 스타일 | display, flex, overflow |

### 3.3 CSS Module 규칙

```
✅ CSS Module에 넣는 것:
   - display, flex-direction, align-items, justify-content
   - overflow, border-radius, transition, cursor

❌ CSS Module에 넣지 않는 것 (MUI sx에 유지):
   - fontSize, fontWeight, color (MUI Typography와 충돌)
   - padding, margin (MUI spacing 단위 사용)
   - 동적 값 (${variable}, 조건부 스타일)
```

## 4. API 연동 가이드

### 4.1 API 클라이언트

```typescript
// src/shared/api/apiClient.ts
import axios from 'axios';

const apiClient = axios.create({
  baseURL: '/api/v1',
  headers: { 'Content-Type': 'application/json' },
});

// JWT 토큰 자동 첨부
apiClient.interceptors.request.use(config => {
  const token = localStorage.getItem('access_token');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});
```

### 4.2 USE_API 토글

```typescript
// src/shared/api/config.ts
export const USE_API = true;   // true: 백엔드 API 사용
                                // false: 기존 localStorage/mock 사용
```

### 4.3 서비스 함수 작성 패턴

```typescript
// services/xxxService.ts
import apiClient from '../../../shared/api/apiClient';
import { USE_API } from '../../../shared/api/config';

// ── 1. 기존 로컬 함수 (fallback) ──
export const loadFormulasLocal = (): Formula[] => {
  const saved = localStorage.getItem('cost-analysis-formulas');
  return saved ? JSON.parse(saved) : initialFormulas;
};

// ── 2. API 호출 함수 ──
export const fetchFormulasApi = async (): Promise<Formula[]> => {
  const res = await apiClient.get('/models/formulas');
  return res.data.data || res.data;
};

// ── 3. 통합 함수 (USE_API에 따라 분기) ──
export const getFormulas = async (): Promise<Formula[]> => {
  if (USE_API) {
    try {
      return await fetchFormulasApi();
    } catch (error) {
      console.warn('API 호출 실패, 로컬 데이터 사용:', error);
      return loadFormulasLocal();
    }
  }
  return loadFormulasLocal();
};
```

### 4.4 개발 프록시 설정

```javascript
// src/setupProxy.js
const { createProxyMiddleware } = require('http-proxy-middleware');

module.exports = function(app) {
  app.use('/api', createProxyMiddleware({
    target: 'http://localhost:8080',
    changeOrigin: true,
  }));
};
```

### 9.2 MUI 스타일 규칙

```typescript
// ✅ 좋은 예: fontSize/fontWeight/color는 sx에
<Typography sx={{ fontSize: 14, fontWeight: 700, color: '#333' }}>

// ❌ 나쁜 예: CSS Module에 fontSize
// .title { font-size: 14px; }  ← MUI와 충돌

// ✅ CSS Module: 레이아웃 속성만
// .container { display: flex; overflow: hidden; }
```

### 9.3 API 호출 규칙

```typescript
// ✅ 서비스 레이어에서만 API 호출
// services/xxxService.ts → apiClient.get(...)

// ❌ 컴포넌트에서 직접 API 호출하지 않음
// Page.tsx → axios.get(...)  ← 금지

// ✅ Hook에서 서비스 함수 호출
// hooks/useXxx.ts → import { getFormulas } from '../services/modelService'
```
